# Draw Plausible Values from a Fitted DIRE Model

This is the second step of the workflow. It accepts the \`mmlcomp\`
object generated by \`Dire_mml()\` and delegates plausible-value
generation to \`Dire::drawPVs()\`.

## Usage

``` r
Dire_drawPVs(x, npv, pvVariableNameSuffix = "_dire", ...)
```

## Arguments

- x:

  A fitted DIRE \`mmlcomp\` object returned by \`Dire_mml()\`.

- npv:

  Positive integer number of plausible values per individual.

- pvVariableNameSuffix:

  Suffix appended to plausible-value column names.

- ...:

  Additional arguments passed to \`Dire::drawPVs()\`.

## Value

The object returned by \`Dire::drawPVs()\`.
